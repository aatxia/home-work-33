# Gulp Project

Цей проєкт показує використання **Gulp**.

## Виконані вимоги
- **SCSS** Налаштовано `gulp-sass`.
- **Автоматичне оновлення сторінки** (`browser-sync`).
- **Autoprefixer** (`gulp-autoprefixer`).
- **Стилі та форматування:** (`style.css`).
